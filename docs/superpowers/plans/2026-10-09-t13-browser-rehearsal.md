# T13 合成数据浏览器彩排

目标：用本机真实 HTTP 服务和真实浏览器把资料确认、职位录入、匹配、草稿、人工批准、DOCX 与人工投递记录串起来。模型使用明确标注的合成替身，不调用外部服务或招聘网站。

质疑：T10 已有分离的页面冒烟和 API 集成测试；重复这些不会增加多少可信度。新增验收只针对它们之间的接缝，遇到失败先定位现有行为，不引入新产品框架。浏览器扩展、真实模型指标和网站兼容性仍不属于本次范围。

1. 新建一项标记为 integration 的浏览器测试，使用临时 PostgreSQL、合成事实和替身模型、本机 Uvicorn、已有 Edge/Playwright。测试从浏览器页面确认资料与事实、保存/解析 JD、显示证据、启动草稿、人工批准、请求 DOCX、保存来源明确的人工记录。验收：每一步有页面断言，后端审批与应用记录相互匹配；没有真实投递。
2. 运行该测试并修复发现的阻塞；保存执行环境、命令、结果和已知限制。测试不纳入无 Docker 的离线 CI；机器缺 Playwright/Edge 时应明确跳过。
3. 独立只读复核后提交推送分支。若浏览器依赖或服务无法启动，不把此前的模拟页面测试代替本次验收。
