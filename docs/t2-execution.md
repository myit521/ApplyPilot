# T2 资料与事实确认执行记录

开始：2026-10-01；最终验收：2026-10-02。基线：T1 `4dbe6c6`；分支 `codex/facts-confirmation`。仅执行 T2，未推进 T3–T12。

## 实现决策

- 联系资料为单例独立修订；教育仅存为结构化教育事实，GET profile 关联教育事实及其独立确认状态/修订，无重复可编辑教育副本。
- 导入模型只能提供内容字段，不能指定身份、来源级别、证据、修订和确认。导入为 model 草稿，人工录入为 human 草稿；证据和确认都只是用户声明，未做外部真实性核验。
- 独立确认接口要求 expected_revision；所有编辑/启停产生新草稿修订，旧修订返回 409。当前记录与历史同事务写入，数据库触发器禁止 UPDATE/DELETE 历史。
- 版本化 SQL 迁移保留旧事实为 legacy 草稿，清除旧嵌入；新库初始化与 CLI 同样执行迁移。就绪检查拒绝旧版本。无需删除数据卷。
- 检索 SQL、合并、生成提示和校验均排除未确认/停用事实。所有确认教育事实在 top-K 外保留，教育段落直接由教育字段构造；数字校验只对教育补充这些结构化字段的数字来源，未扩展 T5 通用策略。
- 事实修改使向量失效；回填按修订条件更新，旧计算不能覆盖并发编辑后的向量。
- 审批/重新生成前拒绝检索快照已变化的事实。此检查是 T2 最小防护，不宣称实现 T7 冻结事务与并发原子批准。
- 页面 /profile 支持联系资料、文字导入、事实新建/编辑/确认/启停及历史，首页可达。内容写入 textContent/value，未保存编辑阻止确认。
