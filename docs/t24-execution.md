# T24：固定事实集上的检索收益评估

在结果产生前固定 `tests/fixtures/t24_retrieval.json`：25 条合成事实，其中 22 条是启用且已确认的非教育事实；9 条人工解析查询中 8 条各有 2 条相关事实，1 条明确没有相关事实。相关性表示事实对岗位技术或职责有用，不等于完全满足岗位要求。人工解析用于隔离 JD 解析误差；这组压力样本不是随机真实岗位样本。

运行本机已缓存的 BGE-small-zh-v1.5，关闭模型下载，记录模型快照、文件哈希和依赖版本。使用独立 Testcontainers PostgreSQL/pgvector，调用生产 `fulltext_hits`、`vector_hits` 和 `merge_and_score`，不读取个人数据库。保持默认混合权重 0.5/0.2/0.3；比较当前关键词+技能基线、仅向量相似度对照和混合规则，未根据结果调参。

主指标是相关事实 Recall@5，逐例保留事实 ID 和分数组成；无相关事实查询的 Recall 为 null，单列返回情况。生产同分排序没有稳定 ID 决胜，本轮保留当前算法，并报告第五名边界同分的 Recall 上下界；范围只针对已召回候选，不覆盖候选上限之外的事实。记录关键词/向量各自的候选数及 20 条候选上限。教育事实的固定保留机制不计入该经验召回指标。

执行入口：`python -m scripts.evaluate_t24_retrieval --model-path <已有本地模型快照目录> --output docs/evaluation/t24-retrieval.json`。已有报告拒绝覆盖；运行失败落盘 failed 状态，不用空向量替身冒充真实评测。

离线回归 200 passed、107 deselected。DSH 在运行前只读核对标注和评测脚本；关于“职责关键词不在基线”和“模型加载不在失败保护内”的意见与实际代码不符，未采纳；候选数量及对照权重记录已补充。本轮未更改生产检索规则。
