# T25：关键词召回的词法边界

T24 记录了两条可复现问题：正文/来源中的 JavaScript 被 Java 查询命中；SQL 技能标签因反向子串比较被 PostgreSQL 查询命中，抬高无关事实的全文得分。

修复将含 ASCII 字母或数字的正文/来源查询词转换为转义后的 PostgreSQL 大小写不敏感边界正则，纯中文仍按子串匹配。技能标签改为完整值比较，去除首尾空白并忽略大小写。C++、百分号、下划线、方括号和反斜杠按字面量处理，不成为查询通配符或正则指令。资格过滤、候选上限、分值公式和混合权重保持现值。

`tests/test_t25_keyword_boundaries.py` 在真实临时 PostgreSQL 上先复现 5 项失败，修复后 11 项边界测试和 7 项既有数据库测试通过。完整回归 `python -m pytest -p no:cacheprovider -q --tb=short`：318 passed、3 warnings。DSH 只读复审未发现新增具体缺陷；复审建议中的“重复词因分隔符消耗而漏计覆盖率”不成立，当前分值按每个查询词是否命中计数，不按出现次数计数。
