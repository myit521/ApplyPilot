# T6 编辑与反馈执行记录

开始与验收：2026-10-04。基线：`d8a7b41`；分支：`codex/t6-feedback`。沿用 LangGraph checkpoint 保存草稿修订，不增加表或迁移。

## 实现内容

- 拒绝审批时记录反馈，并将它放入下一轮生成请求；系统提示明确反馈不能覆盖事实、引用和贡献范围规则。
- 审核页显示草稿修订号，允许只编辑已有主张文本。客户端不能增删主张或修改事实引用；服务端保留每条主张的 fact IDs 和匹配要求，并拒绝改变分区主张数量。
- 手工编辑写入新修订后重新运行 T5 确定性与语义校验。校验失败可按既有规则反馈再生成；不能直接进入批准。
- 审批和编辑请求都带 `expected_revision`。提交过期修订或工作流已离开审批中断点时返回 409；结构不符返回 422。
- 审核页按分区和位置显示上一版与当前版差异、当前事实引用和校验问题。已批准版本不能在原工作流内修改；再次调整须新建工作流。
- API 集成夹具固定使用空向量替身，避免此功能测试尝试下载嵌入模型。无数据库迁移；没有调用真实模型。

## 边界

当前编辑只支持改写已有主张文本，不支持增删或移动主张；这样可原样保留生成时的事实引用。差异按分区和列表位置配对，不做语义级文本 diff。审批快照事务、历史版本快照和重复批准幂等仍属于 T7；工作流进程内线程和重启恢复仍属于 T8。
