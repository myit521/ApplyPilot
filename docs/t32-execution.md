# T32：默认适配器的完整合成浏览器验收

日期：2026-10-20。基准 `f1c8fa3`，T31 托管离线测试作业已成功（run 39356886060）。继续草稿 PR #1，不合并。

## 开始前的方案审查

T13 已验证浏览器主流程，但用的是直接返回字符串的 DemoAdapter；T31 验证了传输、日志和图执行，尚未将默认适配器与完整页面操作串起来。继续增加用量账本前，先补这一证据缺口。此次增强原有浏览器测试，不复制另一套服务/容器，不预设业务代码需要修改，也不调用真实供应商。

## 验收范围

`tests/test_t13_browser_rehearsal.py` 使用临时 PostgreSQL、真实本机 HTTP 服务和 Edge。create_app 不注入替身适配器，临时设置合成模型配置；只在 httpx.post 的供应商边界返回合成响应，默认 DeepSeek 的输入/输出检查、usage 处理、日志、工作流及数据库路径继续执行。嵌入仍使用 NullEmbeddingProvider，不能据此验证真实向量检索。

页面步骤为资料/事实草稿并确认 → 职位保存/解析/匹配 → 启动工作流 → 人工退回 → 编辑并重新校验 → 人工批准 → DOCX → 用户自述 unknown 投递记录。人工批准是测试通过页面点击模拟的决定，不是 Agent 对真实简历的授权。

验证目标：

- 批准前没有批准记录、冻结版本或投递记录；编辑保留事实引用及草稿修订，页面显示修改差异。
- 页面已解析 JD 后，任务复用解析，不再次付费解析。合成供应商共六次响应：页面解析一次、初始生成/复核两次、人工退回生成/复核两次、人工编辑复核一次。
- 六次调用各有一对同 call_id 的开始/结束事件。页面解析不冒充某个任务；初始两次属于 worker attempt 1，人工动作后三次不继承旧 attempt，run/job 关联保持正确。
- 五次返回合法的合成 usage，一次故意缺失；缺失字段保持 null，不当作零费用。所有数值只是测试输入，不是实际 token 消耗、收费或性能收益。
- 批准后只有一个对应修订的冻结版本；DOCX 内的合成资料和修改后文本与版本一致，而不只验证 ZIP 文件头。下载后尚无投递记录，人工记录绑定这个批准版本，来源为 user_reported、状态 unknown。
- 批准、导出和人工留痕不追加模型调用；日志及可选摘要不含提示词、生成原文或密钥。

## 复现与证据

需要 Docker、测试依赖及本机 Edge，缺失浏览器时跳过不算通过：

```powershell
docker info
python -m pytest -p no:cacheprovider -q tests/test_t13_browser_rehearsal.py
```

可选 `APPLYPILOT_DEMO_ARTIFACT_DIR` 指向本机忽略目录，保留合成审核/记录截图及经过字段白名单限制的调用摘要。截图、导出和调试文件不随公开仓库发布。不要把该变量指向个人资料或已有工作文件目录。PowerShell 使用后恢复原环境变量，不将合成模型配置持久写入系统。

首次浏览器执行走完人工操作、DOCX 与数据库断言后，日志断言失败：测试误把页面解析标为图 parse_jd，实际页面调用本就未绑定节点，已修正预期为 null。检查实际事件还发现真实缺陷：task_repo 生成 `wf_` 加 32 位 UUID hex，T31 只校验裸 UUID，导致默认生产任务的 run_id 全部被清空。此前纯 UUID 图测试没有覆盖这个生产格式。

补入相同图/worker 测试的生产 ID 变体，旧过滤器下 **1 failed、3 passed**，失败直接显示任务 run_id 为 null。最小修复只允许精确的 `wf_[0-9a-f]{32}` 和既有合法裸 UUID，保留原字符串供关联；未放行任意 wf_ 文本。补充带前缀的非法标识仍被隐藏的回归。修复后图/观测用例 **21 passed**。历史 wf_ 加任意自定义文本仍不作为可公开记录的标识，不因本轮放开。

修复后的浏览器复验为 **1 passed、3 warnings in 14.31s**，没有跳过。实际摘要为六次供应商替身请求、六对开始/完成事件；首次页面解析未绑定任务，后五次均保留数据库生成的 wf_ 任务 ID 和 job ID，初始两次 attempt=1、人工后三次 attempt=null，usage 为五次 reported、一次 missing。截图和字段白名单摘要留在 `.pytest_cache/t32/artifacts/`，主审核对页面及摘要，不提交这些本机产物。

本轮不是新增一套业务流程：复用并增强原 T13 彩排，删除不再使用的 DemoAdapter。业务修复只涉及日志中生产 ID 格式的兼容，不修改任务 ID 的生成、数据库、状态机或审批规则。

委派的实现 Agent 仅修改指定测试文件，不执行测试或提交。主审核对候选、实际运行并处理首次失败：纠正页面解析的预期，独立定位并修复生产 ID 兼容。新的无历史独立审查 Agent 只读核对限定源码、测试和本记录，未发现待修复缺陷，未运行测试；其未读应用工厂的范围限制由主审补查：api.py 的 get_adapter 在 adapter=None 时确实构造 DeepSeekAdapter，测试无 adapter 参数。此前外部 CLI 多次限定调用无输出，本轮没有重复派发同一阻塞通道，也未放宽权限。

最终执行 `python -m pytest -p no:cacheprovider -q --tb=short`：**398 passed、3 warnings in 136.57s**。包含 PostgreSQL、备份恢复、任务中断恢复及增强后的默认适配器浏览器流程；浏览器未跳过。两项新增参数变体覆盖生产 wf_ ID 和带此前缀的非法文本，未用重复复制端到端流程增加通过数。警告仍为 Testcontainers/websockets 弃用项。本机执行记录与产物保留在忽略目录；托管 CI 只运行非 integration 测试，不把本机 Edge 彩排描述成托管执行。

## 边界与下一步

这是供应商 HTTP 替身下的控制流、输入/批准一致性和观测验收，不是默认适配器的真实模型质量、真实计费、招聘网站兼容或 DOCX 多页视觉验收。语义复核在本例按合成响应通过，不能据此证明内容判断准确。T27 的真实模型单例仍保持原有范围，不被本次结果替代或扩大。

本机单用户 MVP 的主流程与故障测试已优先建设。下一步整理交付版本和剩余发布条件；持久化费用配额、认证、多用户、真实招聘网站辅助与公开部署均不因本次验收自动开启。继续保留人工确认及 user_reported/unknown 的来源边界。
